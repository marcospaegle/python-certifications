## 2. Syllabus – PCEP-30-03 (Blueprint v1.5)

35 objectives, with 1 exam item per objective.

| # | Section | Weight | Questions |
|---|---|---|---|
| 1 | Computer Programming & Python Fundamentals | 17% | 6 |
| 2 | Control Flow: Conditional Blocks & Loops | 23% | 8 |
| 3 | Data Collections: Lists, Tuples, Sets, Dictionaries, Strings | **26%** | 9 |
| 4 | Functions & Exceptions | 20% | 7 |
| 5 | File Handling & Module Imports | 14% | 5 |
| | **Total** | **100%** | **35** |

### Section 1 – Computer Programming and Python Fundamentals (17%, 6 items)

**1.1 Programming Language Fundamentals**
- **1.1.1** Language structure and code execution: lexis, syntax, semantics; lexical, syntactic and semantic errors; interpreters vs compilers; how Python source code is executed.

**1.2 Python Program Logic and Structure**
- **1.2.1** Structural rules: keywords (and why they can't be identifiers); expressions vs statements vs keywords; indentation for code blocks and indentation errors; comments.

**1.3 Literals and Variables**
- **1.3.1** Literals: `int`, `float`, `str`, `bool`; Boolean literals; numeric literal forms; float precision limits; string quoting.
- **1.3.2** Variables: assignment, reference semantics, valid names, PEP 8 naming conventions.

**1.4 Operators, Expressions, Console Operations**
- **1.4.1** Operators: arithmetic (`**`, `*`, `/`, `%`, `//`, `+`, `-`); string `+` and `*`; assignment and augmented assignment (`+=`, …); unary vs binary operators; precedence and associativity; `not`, `and`, `or`; relational operators (`==`, `!=`, `<`, `<=`, `>`, `>=`).
- **1.4.2** Console I/O and type conversion: `print()`; `input()` (always returns `str`); `int()`, `float()`, `str()`; simple input → process → output programs.

### Section 2 – Control Flow: Conditional Blocks and Loops (23%, 8 items)

**2.1 Conditional Execution**
- **2.1.1** `if` and `if-else`; Boolean conditions; tracing branches; blocks that get skipped.
- **2.1.2** `if-elif-else`; evaluation order; the fallback `else`; unreachable or misordered branches.
- **2.1.3** Compound and nested conditionals; spotting redundant or unreachable branches.

**2.2 Iterative Execution**
- **2.2.1** `while` loops; sentinel values; infinite loops; the walrus operator `:=`.
- **2.2.2** `for … in` over strings, lists, tuples and other iterables.
- **2.2.3** `range()` with start/stop/step, including negative steps.
- **2.2.4** Nested loops; combining loops with conditionals.
- **2.2.5** `break`, `continue`, `pass`.

### Section 3 – Data Collections (26%, 9 items)

**3.1 Lists**
- **3.1.1** Creation; positive and negative indexes; slicing; copying via slicing.
- **3.1.2** `append()`, `insert()`, `index()`; removal with methods or `del`; `sorted()` and sorting; iteration; `in` / `not in`; `len()`.
- **3.1.3** Lists of lists (2D/3D matrices); multi-index access and modification.

**3.2 Tuples**
- **3.2.1** Empty, single-element (`(x,)`) and multi-element tuples; indexing and slicing; immutability vs lists; nesting tuples and lists.

**3.3 Sets**
- **3.3.1** Set characteristics (unordered, unique); creation; no positional indexing; add/remove methods; membership tests.

**3.4 Dictionaries**
- **3.4.1** Key–value creation; access and membership by key; adding and updating; removal; iterating with `keys()`, `values()`, `items()`.

**3.5 Strings**
- **3.5.1** Single, double and triple quotes; escape sequences; quotes inside literals; multiline strings; indexing; slicing; immutability; `len()`; substring membership (`in`).
- **3.5.2** Methods: `lower()`, `upper()`, `capitalize()`, `title()`, `swapcase()`, `find()`, `split()`, `join()`, `strip()` / `lstrip()` / `rstrip()`, `replace()`. All of them return **new** strings.
- **3.5.3** Formatting: f-strings, `str.format()`, legacy `%` formatting.

### Section 4 – Functions and Exceptions (20%, 7 items)

**4.1 Functions**
- **4.1.1** `def`; naming; indentation; invocation; order of execution.
- **4.1.2** `return`; using return values; `return` vs `print()`; early termination; multiple return statements; implicit `None`.
- **4.1.3** Parameters vs arguments; positional and keyword arguments; default values; `print()`'s `sep` and `end`; invalid calls.
- **4.1.4** `*args` (tuple) and `**kwargs` (dict); combining parameter kinds.
- **4.1.5** Local vs global scope; name resolution; shadowing; the `global` keyword; risks of using globals.

**4.2 Exceptions**
- **4.2.1** Why exceptions exist; how they interrupt program flow; `ValueError`, `TypeError`, `ZeroDivisionError`, `IndexError`, `KeyError`, `NameError`.
- **4.2.2** `try` / `except`; specific and multiple `except` branches; tracing exception flow.

### Section 5 – File Handling and Module Imports (14%, 5 items)

**5.1 File Handling**
- **5.1.1** Modes `r`, `w`, `a`; reading, writing, appending; the `with` statement; common file errors (e.g. `FileNotFoundError`).
- **5.1.2** CSV structure; the `csv` module; `csv.reader()`, `csv.writer()`; processing rows.

**5.2 Modules and Imports**
- **5.2.1** Why we import; the `import` keyword (and its forms).
- **5.2.2** `math`: `ceil()`, `floor()`, `trunc()`, `sqrt()`.
- **5.2.3** `random`: `random()`, `seed()` (repeatable results), `choice()`, `sample()`.

> **New in 30-03 compared with 30-02 (based on the topics above):** walrus operator, sets, f-strings/`format()`/`%`, `*args`/`**kwargs`, file handling, the `csv` module, and the `math`/`random` modules. Study these carefully if you're using older PCEP-30-02 material.
